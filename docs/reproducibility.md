# Reproducibility

## Reproducibility level

This repository supports reproduction of the public analysis figures from
the consolidated experimental datasets.

The public workflow is:

```text
consolidated experimental data
            ↓
portable plotting scripts
            ↓
public figures
```

The complete raw ns-3 logs are not required for this workflow.

## Tested environment

The scripts were tested with:

```text
Python       3.10.12
NumPy        2.2.6
pandas       2.3.3
Matplotlib   3.10.9
```

Create an isolated environment with:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Generate all figures

From the repository root:

```bash
python3 scripts/generate_all.py
```

The script resolves paths relative to the repository and can also be invoked
from another working directory.

A successful run ends with:

```text
ALL PUBLIC FIGURE PIPELINES PASSED — 60 files generated
```

Generated figures are written under:

```text
figures/generated/
```

## Individual pipelines

### E1 bandwidth evaluation

```bash
python3 scripts/plot_e1_bandwidth.py     --summary data/e1_bandwidth/summary_by_bw.csv     --output-dir figures/generated/e1_bandwidth
```

### E1 temporal analysis at 40 MHz

```bash
python3 scripts/plot_e1_temporal.py     --data-dir data/e1_bandwidth/temporal_40mhz     --output-dir figures/generated/e1_temporal_40mhz
```

### E2 scalability

```bash
python3 scripts/plot_e2_scalability.py     --summary data/e2_scalability/summary_by_ues.csv     --output-dir figures/generated/e2_scalability
```

### E3 XR/QoE

```bash
python3 scripts/plot_e3_qoe.py     --summary data/e3_xr_qoe/qoe_summary.csv     --composition data/e3_xr_qoe/qoe_composition.csv     --output-dir figures/generated/e3_xr_qoe
```

## Dataset integrity

SHA-256 manifests are stored under:

```text
provenance/
```

From the repository root, verify them with:

```bash
for manifest in provenance/*SHA256SUMS; do
    sha256sum -c "$manifest"
done
```

All referenced files should report `OK`.

## Generated figures and thesis figures

The repository keeps two figure sets:

- `figures/generated/` contains figures regenerated by the portable public
  scripts from the consolidated datasets.
- `figures/thesis/` contains the final figure files archived from the thesis
  workflow.

The public scripts were reorganized to remove dependencies on the original
server directory structure. The regenerated figures preserve the same data,
metrics, and scientific interpretation, but are not required to be
byte-for-byte identical to the archived thesis figures.

## Public versus original processing pipeline

The original workflow included raw ns-3 simulation logs, intermediate
post-processing, validation scripts, consolidated tables, and plotting
scripts.

This public repository intentionally starts from the validated consolidated
tables:

```text
original workflow:

raw ns-3 results
    ↓
post-processing and validation
    ↓
consolidated tables
    ↓
thesis figures


public workflow:

consolidated tables
    ↓
portable plotting scripts
    ↓
generated figures
```

Selected validation outputs are retained under:

```text
provenance/validation/
```
